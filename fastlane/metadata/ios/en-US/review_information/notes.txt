1. Screen recording: attached (iPhone, latest iOS, 1 min 40 s). It starts with the app launch and shows the typical flow: saving a recipe under tags, finding it by one tag and by two, hosting a sync with a second phone, opening a record's details. The app has no account registration, login or deletion, no content shared between users and no paid content, so none of those flows exist to record. The sync step needs a second device on the same Wi-Fi; every other feature works on one phone with no network, and the reviewer can skip sync.

2. Purpose and audience: AIS Index is a personal, offline index. The user saves links, notes, file paths, commands and passwords under tags of their own choosing, and finds them later by typing those tags. Target audience: anyone who wants to find their own things again without a cloud account. The problem it solves: a search engine or an automatic tagger answers with what words mean to most people, while the user needs what a word meant to them when they saved it. The value is a private, plain-text index that stays on the phone and outlives the app.

3. Setup and access: nothing to set up. Launch the app, tap +, type a value (a link, a note, a password) and one or more tags, Save. Type a tag in the search field to recall it; two tags return what was saved under both. Tags lists every tag used; Recent lists everything saved. No login, no demo credentials and no sample files are needed: the app starts with an empty index and the reviewer creates records in seconds. A secret saved with the Encrypt switch is encrypted on the device with a passphrase the user types; the app never stores or transmits the passphrase.

4. External services, tools and platforms: none. The app runs a C engine built into the binary and uses only iOS system frameworks. Voice input uses Apple's Speech framework with on-device recognition requested, so audio is not sent to a server. Sync, when the user chooses it, runs directly between two of the user's own devices on the same Wi-Fi: one shows a QR code, the other scans it, and the transfer is end-to-end encrypted over the local network (hence NSLocalNetworkUsageDescription). Export writes one file the user can share with the standard share sheet. There is no server, no analytics, no crash reporting, no authentication service, no payment processor, no advertising and no AI service.

5. Regional differences: none. The app functions identically in every region where it is offered, with one listing in English.

6. Regulated industry or protected material: none. The app is the author's own open-source work (github.com/Anode1/ais, MIT licence for the App Store binary) and includes no third-party content. Encryption uses standard algorithms; export compliance is already answered as exempt.
